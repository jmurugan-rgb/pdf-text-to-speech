# 📖 PDF Text-to-Speech Reader

A simple Python program that allows users to select a PDF file and listen to its text aloud.

## ✨ Features

* 📂 Select a PDF file using a file browser
* 📄 Extract text from each PDF page
* 🔊 Convert PDF text into speech
* 📚 Read the entire document aloud

## 🛠️ Technologies Used

* 🐍 Python
* 📘 PyPDF2
* 🗣️ pyttsx3
* 🖥️ Tkinter

## ⚙️ Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the program using:

```bash
python main.py
```

A file-selection window will open. Choose a PDF file, and the program will read the text aloud.

## 📝 Note

This program works best with PDFs that contain selectable text. Scanned image-only PDFs may not work properly.
